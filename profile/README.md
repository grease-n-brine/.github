# Grease & Brine

Building and researching software across systems programming, machine learning, and computational modeling. The work ranges from reusable C++ libraries to focused implementations and research experiments.

## Areas of work

- **Machine learning infrastructure:** data-processing libraries, tensor components, and estimation tools.
- **Applied machine learning:** from-scratch models, sequential learning, and reinforcement learning studies.
- **Research and evaluation:** experimental systems with documented methods, results, and limitations.
- **Control and simulation:** state estimation, control systems, and physical models.

Projects are at different stages of development; each repository's README is the best source for its current scope and status.
