# Grease & Brine

Grease & Brine builds and studies software across systems programming, machine learning, and computational modeling. The work ranges from reusable C++ libraries to focused implementations and research experiments.

## Areas of work

- **Machine learning infrastructure:** data-processing libraries, tensor components, and estimation tools.
- **Applied machine learning:** from-scratch models, sequential learning, and reinforcement learning studies.
- **Research and evaluation:** experimental systems with documented methods, results, and limitations.
- **Control and simulation:** state estimation, control systems, and physical models.

## Selected projects

- [NE-PP](https://github.com/grease-n-brine/ne-pp) — a C++ data-processing and machine-learning library, alongside [NE-Lattice](https://github.com/grease-n-brine/ne-lattice), a tensor library, and [NE-ESTAC](https://github.com/grease-n-brine/ne-estac), a state-estimation and kinematic-filtering library.
- [Attention Fabric](https://github.com/grease-n-brine/attention-fabric) — a Java research framework for spatially organized, adaptive networks. The repository includes reproducible experiments and reports both positive findings and limitations: current results support anomaly response, but not function approximation.
- [DQN/PPO Crafter study](https://github.com/grease-n-brine/dqn-ppo-crafter-paper) — an evaluation of value-based and policy-gradient reinforcement learning as action-space complexity increases.

Projects are at different stages of development; each repository's README is the best source for its current scope and status.
